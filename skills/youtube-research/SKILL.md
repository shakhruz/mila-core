# YouTube — читать видео, а не пересказывать по памяти

Бесплатный путь (`youtube_info`) с нашего сервера не работает — YouTube просит вход.
Рабочие инструменты три, все платные через Apify, цена копеечная, повтор — из кэша за $0.

## Когда какой инструмент

- **Человек прислал ссылку на видео** → `youtube_video(url, lang="ru")`.
  Отдаёт название, канал, дату, просмотры, длительность, описание и транскрипт
  с таймкодами `[м:сс]`. ≈$0.005 (≈130 сум), повтор 30 дней бесплатно.
- **Нужно найти видео по теме** → `youtube_search(query, limit=10)`.
  Строки: дата · длительность · просмотры · канал · название · ссылка.
  ≈$0.003 за видео в выдаче (10 видео ≈ 800 сум), повтор сутки бесплатно.
- **Разбор человека или компании** → `youtube_channel(url, limit=10)`.
  Подписчики, сколько видео всего, последние ролики. Цена как у поиска.

Порядок для темы: `youtube_search` → выбрать 1–3 ролика → `youtube_video` по каждому.
Не тяни транскрипт всех десяти — это долго и человеку не нужно.

## Что делать с транскриптом

- **Конспект**: 5–10 тезисов своими словами, каждый — с таймкодом, где это сказано.
- **Цитаты**: дословно из транскрипта, в кавычках, с `[м:сс]`. Автосубтитры без
  знаков препинания — расставь их, слова не меняй.
- **Темы**: назови 3–5 блоков видео по таймкодам («0:00–4:10 — что такое стресс»).
- Транскрипт показывается до 12 000 знаков; если обрезан, инструмент скажет, сколько
  всего — повтор с `max_chars=<всего>` отдаст остальное бесплатно из кэша.
- Язык: `lang="ru"` по умолчанию; для узбекского `lang="uz"`. Если субтитров на
  этом языке нет, инструмент возьмёт доступный и скажет об этом — не скрывай.

## Честность

- Цифры (просмотры, подписчики, дата) — только из ответа инструмента, с датой сбора.
- Видео не найдено / закрыто — так и говори; не подбирай «похожее» без спроса.
- «Транскрипт недоступен» = у видео нет субтитров; пересказывать по названию нельзя.
- Не выдавай чужой текст за свой: конспект — да, копия транскрипта наружу — нет.

## Про цену

Перед серией (больше 5 видео с транскриптом) назови человеку порядок цены:
«разберу 10 роликов, это около 700 сум». Один ролик — без предупреждения.
