# 📝 Черновик по образцам
Когда: типовой вопрос — цена, сроки, «а что вы делаете», «как начать».
1. `dialogs_dialog(who)` — контекст этого человека (куплено, предложено, обещания).
2. Образцы: три последних НАШИХ ответа на такой же вопрос, за которыми пришло «спасибо/ок/понял/беру» (история диалогов, `read_dialog`). Беру тон и структуру, не копирую дословно.
3. Черновик ≤ 400 знаков, на языке собеседника, факты только из карточки и прайса кассы.
4. Черновик — владельцу с кнопками (Отправить / Правки), не клиенту напрямую.
Запрещено: цифры не из прайса; тариф ниже купленного; «сверю/уточню» без вызова инструмента в том же ходе.
Мера: доля черновиков, ушедших без правки владельца, > 60 % на второй неделе.
