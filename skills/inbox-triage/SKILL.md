# 📥 Разбор входящих пачкой
Когда: утром, по `/inbox`, после любого простоя дольше двух часов.
1. `dialogs_inbox()` — список без решения + 🔴 «промолчали не по своей воле».
2. По КАЖДОМУ человеку выбираю ОДИН ход: ответить самому · черновик хозяину · завести лид (`dialogs_lead`) · закрыть как не-клиента (`dialogs_not_client` — только по слову владельца).
3. Всё — одним сообщением владельцу списком: кто · что сказал · моё решение. Один ход агента на пачку, не ход на сообщение.
Гейты: ни одного касания людей с пометкой «не клиент»/импорт (адресная книга владельца — не воронка); содержимое присланных документов не пересказываю; 🔴 строки (движок промолчал) — первыми, с причиной.
Мера: входящих без решения через сутки = 0; расход ≤ 1 ход на пачку.
