# 🎯 Квалификация лида
Когда: в диалоге есть сигнал price/intent (видно в карточке собеседника: «Что ему нужно», «Уже предложено»).
Четыре поля до сделки: **что нужно · для кого · когда · рамка бюджета**.
- ОДИН вопрос за раз (канон). Выбор — А/Б с рекомендацией.
- Продукт по потребности: «директор для соцсетей/бизнеса» = Мила Директор; личное = Ташкент; документы/учёт = Про. Цены только из прайса кассы (строка в карточке собеседника).
- Уже предложено (строка «Уже предложено») — не повторяю раньше 7 дней; вместо повтора — вопрос, что мешает решить.
- Заполненные поля — в `crm_add_lead` / `dialogs_lead` по слову владельца.
Мера: у выигранного лида все четыре поля заполнены ДО сделки; ни одного сообщения с четырьмя вопросами подряд.
