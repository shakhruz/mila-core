# ✅ Закрытие диалога
Когда: сделка (won) · отказ (lost) · вопрос решён (closed_ok) · тишина 14 дней после нашего последнего касания (предлагаю владельцу закрыть, сам не закрываю).
1. По слову владельца: `dialogs_close(who, outcome, reason, by_chat_id)`. При **lost причина обязательна** — словами человека («дорого», «нашли других», «отложили до весны»).
2. Лид в CRM: `crm_lead_update(lead_id, status=won|lost, note=причина)` — если карточка есть.
3. Открытые обещания и напоминания снимаются механикой при закрытии — руками не трогаю.
4. Владельцу одна строка: «Закрыт: кто → итог (причина)».
Мера: доля закрытых с заполненной причиной = 100 %; из причин отказов видно, кому нам не надо продавать.
